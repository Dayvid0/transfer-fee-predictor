# Triage Labels

The five canonical triage labels for this repo:

- `needs-triage` - Issue needs triage
- `needs-info` - More information needed
- `ready-for-agent` - Ready for agent work
- `ready-for-human` - Ready for human work
- `wontfix` - Won't be fixed

**Usage:**
- These labels are applied via the `/triage` command
- Issues should have exactly one triage label at any time
- Labels help route issues to the appropriate owner/agent
