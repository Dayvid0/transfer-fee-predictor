Build a football transfer fee prediction pipeline in Python, inside
this folder only. Use synthetic data so it runs end to end with no
internet. First give me a 5-line plan, then build it.

CONSTRAINTS
- Machine has 7.5 GB RAM, 2 CPU cores, no GPU. Use pandas, numpy,
  scikit-learn, lightgbm (n_jobs=2). No deep learning.
- Use the .venv in this folder. Never use sudo or install globally.
  Keep requirements.txt updated. Don't touch files outside this folder.
- Keep each file under ~200 lines.

DATA (synthetic, generated by src/make_data.py, seeded)
Generate ~5,000 transfers, seasons 2015-2025, with columns: player_id,
season, age, position, league, goals_p90, assists_p90, xg_p90,
minutes, contract_years_left, market_value_eur, fee_eur. Build fee_eur
from a realistic hidden formula: age peak around 24-27, more
goals/xG and longer contracts raise the fee, ~10% yearly inflation,
league strength effect, plus lognormal noise. Also add a few loans/
free transfers (fee = 0) to be filtered out.

PIPELINE
- src/features.py: filter fee > 0, target = log1p(fee_eur), add age^2,
  per-90 features, season index. Use only info available before the
  transfer (do not use post-transfer data as features).
- src/train.py: split by TIME (train seasons <= 2022, test 2023+),
  never random. Models: (A) baseline = market_value_eur,
  (B) linear regression on log fee, (C) LightGBM.
- src/evaluate.py: MAE on the log scale and in EUR for all three
  models in one table, LightGBM feature importance, and the 10 worst
  errors.
- main.py runs everything and writes reports/results.md.
- tests/: at least 3 tests, including one proving no test-season
  rows appear in training.

RULES
- Run the code and tests yourself and fix errors before finishing.
- Never claim something works unless you ran it and saw the output.
- Commit to git when tests pass.
- Finish with a short summary: what exists, the results table, and
  any assumptions you made.
